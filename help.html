剪贴板守卫

防范常见网页复制劫持，并在普通网页粘贴前检查内容是否与已记录的文本一致。它无法冻结 Windows 剪贴板，也无法清除木马。

移动悬浮条（1.2.0）

按住顶部「当前剪贴板」标题区域即可拖动；收起的小条也可按住移动，单击则展开。双击标题回到右下角。窗口缩小或展开预览时会自动调整位置，避免移出屏幕。位置仅在当前页面保留，刷新后回到默认位置。也可用 Tab 聚焦标题后按方向键移动，Shift 加方向键加速，Home 键复位。

页面上的当前剪贴板

1.1.0 版在普通网页右下角显示独立的剪贴板悬浮条。常见 42 位地址可完整显示；长文本可展开，最多预览前 4096 个字符，并显示原文字符数。页面获得焦点且处于前台时每秒尝试更新一次；也可点击「刷新」。普通 HTTP 网页可能需要手动刷新。

切到其他软件或后台标签页时暂停读取，返回后更新。点击「−」收起也会暂停，点击「剪贴板 · 展开」恢复。界面显示的是最近一次成功读取的快照，可能漏掉两次读取之间的变化；不能识别修改剪贴板的程序。预览不会更新可信记录或锁定状态。

原文显示在扩展来源的独立框架内，不写入宿主网页 DOM，不通过网页消息发送，不保存到存储。网页脚本不能直接读取该框架里的文本；屏幕截图仍会包含显示的内容。

日常使用

  1. 安装后刷新已经打开的网页。点击扩展图标，检查当前页面是否连接。
  2. 手动选中文本，按 Ctrl+C 或使用浏览器右键菜单复制。扩展以纯文本复制，并保存 SHA-256 摘要。剪切保留浏览器默认删除行为。
  3. 按 Ctrl+V 或使用浏览器粘贴菜单。内容一致才向普通文本框插入纯文本；不一致则停止并提醒。
  4. 重要地址复制后，可点击扩展图标 → 锁定记录。后续复制不会更新该记录。用完后解除锁定。

从其他程序复制

扩展无法知道微信、记事本或地址栏里的原始复制内容。第一次粘贴可能提示没有记录，或者与旧记录不一致。这不等于已中毒。点扩展图标 → 读取当前剪贴板并检查，与可信原文逐字核实；必要时在框内输入正确原文，再点“确认可信并复制”。不要盲目把收到的可疑文本设为可信。

兼容性与限制

  • 严格模式会阻止常见的网页脚本 writeText、write 和 execCommand 复制/剪切调用，因此网站自带复制按钮可能失效。请手动选中后复制。
  • 粘贴需要异步校验，再以纯文本插入。支持普通 input、textarea 和部分 contenteditable；邮箱/数字框、封闭 Shadow DOM、自绘/复杂编辑器、文件/图片/富文本粘贴可能不支持。校验期间请勿切换焦点或输入。
  • 逐字符核对，包括空格、换行和大小写。上限 262,144 个 JavaScript 字符单元。超限或无文本时阻止粘贴，不会自动放行。
  • 只覆盖扩展获准运行的 HTTP/HTTPS 页面及匹配的子框架。Chrome 内部页、商店页、内置 PDF、其他扩展页面、本地文件、浏览器地址栏、原生程序不在覆盖范围。安装/更新后须刷新旧页面；无痕需单独授权。
  • 网页环境中的 API 补丁是尽力防护。恶意网页可干扰 MAIN 世界脚本，某些框架时序、其他扩展和系统木马可能绕过拦截。不要当作完整的安全边界。
  • 记录反映选中复制的文本，不证明地址属于谁、来源可信或交易安全。网页还可以在粘贴后修改输入框或交易内容；提交前仍需核对最终收款地址。
  • 未锁定时，多窗口/标签页共用最近一次已登记的复制记录。并发复制可能造成顺序歧义；重要内容使用锁定功能。右键“复制链接地址”、复制图片、无法读取的选区不支持建立记录。
  • 剪切发生后，操作系统可能规范化换行等格式；因此严格校验可能拦截格式变化后的内容。密码输入框的复制不会登记，也不会替换已有记录。
  • 如需临时恢复网站原有复制行为，请在扩展管理页禁用本扩展，并刷新相关网页；重新启用后再次刷新。

隐私与权限

无服务器、无联网、无遥测、无复制历史。仅在 chrome.storage.session 中保存最近一条 SHA-256 摘要、字符数、复制时间、来源域名、锁定状态和不一致计数；不保存复制原文。原文仅在复制/粘贴校验、弹窗和悬浮条显示过程中暂留内存。关闭浏览器会话、重载/禁用扩展会清除会话数据。摘要不是加密保险箱，短文本仍可能被猜测，不要用它存储秘密。

storage 用于临时核对记录；clipboardRead 用于弹窗检查和前台悬浮条每秒读取，clipboardWrite 用于你主动点击弹窗按钮时复制；所有网页内容脚本权限用于在页面载入开始时安装拦截。收起悬浮条可暂停自动读取。
